🏰 FortExplorer

FortExplorer is a Python project that visualizes and analyzes famous forts of India using Pandas, NumPy, and Matplotlib.
It provides insights into fort heights, age, location, and popularity, helping history enthusiasts explore iconic monuments in a fun and interactive way. 🌄

🚀 Features

Load and process real fort data from CSV 🗂️

Calculate age, height, and visitor statistics using NumPy & Pandas 🔢📊

Visualize data with Matplotlib:

Bar charts for fort heights 📊

Timeline of construction ⏳

Map-like scatter plots of locations 📍

Pie chart of forts per region 🌐

Easy to extend and explore with new forts and data 🏯

🛠️ Installation

Clone the repository:

git clone https://github.com/yourusername/FortExplorer.git
cd FortExplorer


Install required packages:

pip install -r requirements.txt


Make sure the forts.csv file is in the data/ folder.

▶️ How to Run
python src/fort_explorer.py


You will see:

Bar charts of fort heights 📊

Timeline of construction ⏳

Map-like scatter plots with visitor sizes 📍

Pie chart of forts per region 🌐
